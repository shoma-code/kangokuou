ルールブック

RULE BOOK // CURRENT RULES
監獄王 基本ルール
現時点で決定している共通ルールをまとめたルールブックです。 カード固有の効果や記述が共通ルールと異なる場合は、原則としてカード側の記述を優先します。
01 基本構成 BASIC STRUCTURE
  • カードには人タイプ、神タイプ、クリーチャータイプ、道具タイプ、空タイプの5種類があります。
  • バトル中の主なプレイエリアは、山札（デッキ）、手札、墓地、バトル場です。
  • バトル開始時のライフはお互いに5です。
  • バトル開始前にじゃんけんを行い、勝ったプレイヤーが自分の初期手札を確認したうえで先攻・後攻を選びます。
  • バトル開始時、お互いに山札から5枚引いて初期手札とします。
02 デッキ構築 DECK BUILDING
  • デッキ枚数は40〜100枚です。
  • 同じカードは原則として3枚までデッキに入れられます。
  • 神タイプカードはデッキに1種類まで入れられます。同じ神タイプ1種類の範囲内で、通常の投入枚数制限に従います。
  • カード固有の投入制限がある場合は、その記述を優先します。
  • 《ただの人》はカード固有ルールにより、投入枚数制限なしです。ただし所持枚数を超えて登録することはできません。
  • No.031《台ファン結成》、No.042《起死回生》はカード固有ルールにより1枚までです。
03 勝敗条件 WIN / LOSE
  • 相手プレイヤーへダイレクトアタックを行うと、基本的に1回の攻撃につきライフを1減らします。
  • 相手のライフを0まで減らしたプレイヤーが勝利します。
  • 自分の山札が0枚になった場合、そのターンのエンドステップに敗北します。
04 ターンとステップ TURN FLOW
STARTスタートステップ
DRAWドローステップ
MAINメインステップ
ATTACKアタックステップ
ENDエンドステップ
  • 各ターンの開始をスタートステップと呼びます。
  • 自分のスタートステップごとに、自分のCOUNTを+1します。
  • スタートステップの後にドローステップへ進み、山札から1枚ドローします。
  • カードを召喚・使用する時間をメインステップと呼びます。
  • カードで攻撃する時間をアタックステップと呼びます。
  • アタックステップ後、ターンを終了する時間をエンドステップと呼びます。
05 召喚・カード使用 SUMMON / PLAY
  • バトル場には最大7枚までカードを置けます。
  • 通常の召喚は1ターンに1枚までです。
  • 道具タイプカードは通常召喚の1枚制限とは別に、1ターンに何枚でも使用できます。
  • バトル場に置いたカードは、原則として置いたターンには行動できません。カード効果に例外がある場合はその効果を優先します。
  • 神タイプカードを召喚する場合、自分のバトル場のカード3枚を生贄として墓地へ置いて召喚します。
  • 道具タイプカードは、基本的に効果使用後に墓地へ置きます。
  • 「召喚する」ことでバトル場に出た場合は召喚した時の効果が発動します。
  • 「バトル場に出す」など、召喚以外の方法で場に出た場合は、召喚した時の効果は発動しません。
現在のゲームUIでは、誤操作防止のためカードの召喚・使用は2段階確認になっています。
06 攻撃・ダメージ・破壊 ATTACK / DAMAGE
  • カードのアタックによって相手カードのHPを0以下にした場合、そのカードは破壊されます。
  • 相手のバトル場に攻撃対象となるカードがいない場合、プレイヤーへダイレクトアタックできます。
  • ダイレクトアタックは基本的に相手のライフを1減らします。
  • 「破壊する／破壊される」ことと、単に「バトル場から離れる／別のプレイエリアへ置く」ことは別の扱いです。
  • ただし、破壊によってバトル場から離れた場合は、破壊されたことによる効果とバトル場から離れたことによる効果の両方が条件を満たします。
07 効果・チェーン・HP EFFECT / CHAIN / HP
  • カード効果が連続して発動することをチェーンと呼びます。
  • チェーンした効果は、原則として一番最後にチェーンした効果から先に解決します。
  • カード効果によって、チェーンの解決順が変更される場合があります。
  • カード効果によるHP回復では、そのカードの元のHP+7を上限とします。
08 プラクティスモード PRACTICE MODE
  • 難度は超初級 → 初級 → 中級 → 上級 → 超上級 → 神級の順に解放されます。
  • 現在解放されている最高難度をクリアすると、次の難度が1つ解放されます。
  • 各ステージの初クリア報酬は小松菜5個です。
  • 同じステージの2回目以降のクリア報酬は小松菜1個です。
  • 超初級CPUは、《ただの人》40枚の専用デッキを使用します。
  • 初級CPUは、《ただの人》22枚、《強い人》3枚、《陽気な人》3枚、《Deoxyribo Nucleic Acid》3枚、《UN〇!》3枚、《ただの馬》3枚、《ガルモン》3枚の40枚デッキを使用します。
このルールブックは現段階の仕様です。今後カード効果やモードの追加に合わせて更新されます。
